## 📌 Keep (유지할 것)

### 잘 되고 있는 것들, 계속 유지해야 할 것들

1. **단계적 학습 접근 방식**
   - 처음에는 어려웠지만 단계적으로 익숙해지는 학습 패턴이 효과적이었음
   - 복잡한 내용을 작은 단위로 나누어 학습하는 방식 유지

2. **실습 중심의 학습 방법**
   - 커서 Pro를 활용한 프롬프팅과 프로그램 생성 실습
   - 파이참을 통한 실제 코드 실행 경험
   - 이론보다 실습을 통한 학습이 효과적

3. **도구 활용 능력 향상**
   - 커서 Pro, 파이참, 깃헙 등 개발 도구 사용법 습득
   - 각 도구의 기본 기능을 이해하고 활용할 수 있게 됨

4. **체계적인 학습 내용 정리**
   - 프롬프팅 → 프로그램 생성 → 실행 → 깃헙 등록의 순차적 학습 흐름
   - 각 단계별로 명확한 학습 목표를 가지고 진행

## ⚠️ Problem (문제점)

### 개선이 필요한 부분, 문제가 되고 있는 것들

1. **초기 학습 곡선의 어려움**
   - 처음에는 도구 사용법과 개념 이해가 어려웠음
   - AI 프롬프팅의 효과적인 작성 방법에 대한 이해 부족

2. **깃헙 워크플로우 이해 부족**
   - 저장소 등록과 리뷰 과정에 대한 깊은 이해 필요
   - 브랜치 관리, 커밋 전략 등 고급 기능 학습 필요

3. **프롬프팅 스킬 부족**
   - 효과적인 프롬프트 작성 방법에 대한 경험 부족
   - AI가 원하는 결과를 정확히 도출하는 프롬프트 작성 능력 향상 필요

4. **독립적인 문제 해결 능력**
   - 도구 사용 중 발생하는 오류나 문제를 스스로 해결하는 능력 부족
   - 문서나 자료를 활용한 자가 학습 능력 향상 필요

5. **학습 내용의 깊이**
   - 기본 사용법은 익혔지만, 고급 기능이나 최적화 방법에 대한 이해 부족
   - 각 도구의 심화 기능 학습 필요

## 📝 회고 메모

### 학습 내용 요약

#### 1. 커서 Pro를 활용한 프롬프팅과 프로그램 생성 방법
- AI 기반 코드 생성 도구 활용법 학습
- 효과적인 프롬프트 작성으로 원하는 코드 생성
- 실시간 코드 편집 및 개선 경험

#### 2. 파이참을 활용해서 실행하는 방법과 깃헙에 등록하는 방법
- 파이참 IDE 환경 설정 및 프로젝트 실행
- 코드 작성, 실행, 디버깅의 기본 워크플로우
- 깃헙 저장소 생성 및 코드 업로드 방법

#### 3. 깃헙에서 저장소를 등록하고 리뷰하는 방법
- 깃헙 저장소 생성 및 관리
- 커밋, 푸시, 브랜치 관리 기본기
- Pull Request 생성 및 리뷰 프로세스 이해

### 느낀점
- 처음에는 어려웠지만, 단계적으로 익숙해지는 과정을 경험
- 실습을 통한 학습이 이론 학습보다 훨씬 효과적임을 확인
- 각 도구들이 서로 연계되어 있다는 것을 이해하게 됨
- 작은 성공 경험이 다음 학습에 대한 동기부여가 됨

### 추가 논의 사항
- 다음 주에는 더 복잡한 프로젝트를 통해 학습한 내용을 통합적으로 활용해볼 예정
- 프롬프팅 스킬 향상을 위한 체계적인 학습 계획 수립 필요

### 다음 회고에서 확인할 사항
- Try 항목들의 진행 상황
- 실제 프로젝트 적용 경험
- 프롬프팅 스킬 향상 정도
- 독립적인 문제 해결 능력 개선 여부
