# KPT 회고 프로젝트

이 프로젝트는 **KPT (Keep, Problem, Try) 회고** 방법론을 활용하여 정기적인 회고를 진행하기 위한 템플릿과 가이드를 제공합니다.

## 📁 파일 구조

- `KPT_회고_가이드.md`: KPT 회고 방법론에 대한 상세 가이드
- `KPT_회고_템플릿.md`: 회고 작성 시 사용할 템플릿
- `회고_기록/`: 실제 회고 기록을 저장할 폴더 (선택사항)

## 🚀 빠른 시작

1. **가이드 읽기**: `KPT_회고_가이드.md` 파일을 읽어보세요
2. **템플릿 복사**: `KPT_회고_템플릿.md`를 복사하여 날짜별로 회고를 작성하세요
3. **정기적으로 회고 진행**: 주기적으로 회고를 진행하고 개선사항을 실행하세요

```bash
# 회고 기록 폴더 생성 (선택사항)

```

## 📚 KPT 회고란?

**KPT 회고**는 세 가지 간단한 질문으로 회고를 진행하는 방법론입니다:

- **Keep**: 무엇을 계속 유지할까?
- **Problem**: 무엇이 문제일까?
- **Try**: 무엇을 시도해볼까?

이 방법론은 팀의 지속적인 개선을 위한 간단하고 효과적인 도구입니다.

## 🔄 회고 주기

- **스프린트 회고**: 스프린트 종료 시
- **월간 회고**: 매월 말
- **프로젝트 회고**: 프로젝트 완료 시
- **분기 회고**: 분기별
